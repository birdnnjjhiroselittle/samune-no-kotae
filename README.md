# サムネの答え

学術系YouTube（例：のら学者／考える葦／海外Yパパラジオ）や論文を、**サムネの「問い」への答え＋理由3つ（140字）** にまとめるツールの試作品です。

10分以上の動画を見る前に「で、答えは？」がすぐわかるようにしたい、という思いから作りました。

▶ 使ってみる：https://birdnnjjhiroselittle.github.io/samune-no-kotae/

## 使い方

1. 動画のURLを貼る → サムネイルとタイトルが出る
2. 動画の **説明文** か **文字起こし**（YouTubeの「文字起こしを表示」）をコピーして貼る
3. 「AIでまとめる」（自分のClaude APIキーを使う）か、「指示文をコピー」して好きなAIに貼る
4. できあがりを確認・修正して「Xの投稿画面を開く」→ 自分で投稿する

### 出力の例

> 【サムネの答え】結婚を分けるのは年収より「人と接する仕事かどうか」
> ①35〜44歳の正社員の男性は、確かに稼ぎの順に結婚している
> ②でも同じ年収でも営業は83%、技術者は72%が結婚
> ③分かれ目は仕事が人のほうを向いているか（店先か工房か）
> 出典：のら学者 https://youtu.be/7IVO6ZSmOKY

## このように作った理由

| 決めたこと | 理由 |
|---|---|
| 字幕を自動で取らない | YouTubeの規約上、字幕を勝手に取るのはグレー。試したところ「botではないことを確認してください」と止められた |
| 自動では投稿しない（Xの投稿画面を開くだけ） | X APIは有料。それに、作った人に断らず「答え」だけを流し続けると、元の動画の再生数をうばってしまう |
| 出典とリンクを必ず付ける | 元の動画を見に行く人が増えるように |
| 書いてないことは足さない、とAIに指示 | 要約でうそが混ざるのを防ぐ |
| APIキーはブラウザの中にだけ保存 | サーバーを持たない、静的なページ（GitHub Pages）だけで動かすため |

## 識者の方に意見をいただきたいこと

1. **YouTube・Xの規約**：要約＋出典リンクを公開でポストするのは、どこまでならOKでしょうか？ チャンネルの持ち主に許可をもらう仕組みが必要でしょうか？
2. **新着の自動チェック**：公式RSS（`feeds/videos.xml`）で新着の説明文を取る形にしたいのですが、試したところ404でした。YouTube Data API（公式・無料枠あり）を使うのがよいでしょうか？
3. **文字起こし**：説明文がうすい動画のために、規約を守ったまま中身を取るよい方法はありますか？（例：チャンネル側が字幕を公開してくれる仕組み、音声を自分で文字にする、など）
4. **論文**：arXiv などの論文をまとめる場合、アブストラクトだけで足りるでしょうか？
5. **クリエイターとの関係**：「答えがわかったら見なくなる」のではなく、「答えを見て、もっと知りたくなって見る」形にするには、どうしたらいいでしょうか？

意見は [Issues](https://github.com/birdnnjjhiroselittle/samune-no-kotae/issues) にお願いします。

## これからやりたいこと

- 好きなチャンネルの新着を自動でまとめた一覧ページ
- 論文（arXiv）にも対応
- 「なんだっけAI」（知らない言葉をその人向けに解説するツール）と組み合わせる

## 中身

- `index.html` / `app.js` だけで動きます（ビルド不要）
- AI：Claude API（`@anthropic-ai/sdk` を esm.sh から読み込み、ブラウザから直接呼び出し）
- タイトル取得：noembed.com（YouTubeの公開oEmbed情報）
- サムネイル：`i.ytimg.com` の公開画像
